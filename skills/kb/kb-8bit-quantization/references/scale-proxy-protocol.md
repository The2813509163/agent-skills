# 尺度代理预研：选样、搜索与结论边界

来源：2026-10-23 服务器两轮代理采集与搜索，2026-10-25 回流。结果与报告标识见[本地实测账本](local-evidence.md)第6节；格式见[格式与轴](formats-and-axes.md)，W/A目标见[配方与搜索](recipes-and-search.md)。下述比例、网格和统计量是该案例的可复用起点，不是所有项目的必跑配置。

## 0. 什么时候做

- 回答“某条尺度规则值不值得进整模”，不直接回答“掉多少点”。
- 候选多、整模昂贵时有价值；候选少或真实评测已足够便宜，可直接做整模。
- 先定问题、预算和停止条件；不为采用本协议扩大原实验范围。

## 1. 选样：按输入统计筛，不按结果筛

- 用格式无关统计排名：实际通道最大值、抽样q99、尾部能量；保留困难组与普通对照。
- 不按“哪个格式赢”筛样本；筛选压力集不能代表部署分布的发生率。
- 稀少token专家不能无声排除；按覆盖目标补样本，保留行数门槛与缺口。
- 原案例按语料前80%/后20%划分fit/transfer，窗口不重叠，并避开既有校准与上一轮候选窗口。新项目按语料结构设计切分；顺序切分也可能有分布差异，不能仅凭比例宣布独立。

## 2. 保留可重放证据

- 原案例以完整调用的X、原W/bias、真实输出Y计算误差；保留文本窗口、模块、层/专家、shape、真实路由行数和选择原因。
- 若为了成本抽行/通道，明确改变了哪个问题和统计总体；不能把切片误差写成完整调用误差。
- 扫描阶段可用近似分位数排名；该案例保留的数据再按精确分位数复算。大张量工具受限时可分块或用CPU实现，先估算内存与成本。
- 关键统计需独立复核；CPU FP64与`math.fsum`是可用路径，具体反例见[诊断](diagnostics.md)第3节，不为每个候选重复重算。

## 3. 固定量化口径

- 比较格式时固定节点、粒度、尺度规则及舍入约定；码本、范围和格式特有行为另行声明。
- 原Attention代理：Q/K在RoPE后；S先乘原模型scaling再加mask；P逐query行定标。新模型以真实计算图为准。
- mask填充值不进有效值的尺度/误差统计；该协议softmax保持FP32，P量化后不重归一化。
- 当前上下文K/V只量化一次，可作为KV8读入的数值代理；不覆盖缓存追加的尺度更新，也不代表压缩存储。

## 4. 候选网格：保留基线与扩展规则

- 原案例一维参数化`delta=q99/C`；`C`是格式区间参考点，不是格式最大值。
- 起始`log2(C)`从−4到16、步长0.25，另加Amax及格式最大值对应候选；这不是无需验证的通用网格。
- 只用搜索集决定是否触边扩展、如何细化；验证集不反向调参。Amax也可以胜出。
- 细网格曾找到粗网格遗漏的解；1/8等直觉锚点不是规律。细化只加候选，改变目标函数须另作对照。

## 5. 目标函数与判读

- 原主指标：真实输出的矩阵NMSE，各完整调用等权。若关心部署频率或其他损失，预先声明权重，不能混排。
- 辅助看最大绝对误差、q99内外误差、饱和/归零比例、归一化后稠密区比例及最坏样本。
- 原案例报最差10%案例均值、单个最坏值和普通对照；尾部比例随样本量与问题选择，不只报总体均值。
- 逐组oracle使用真实输出选参，只是该候选集内的误差下界，不是可部署共享规则。
- 联合QKVP等阶段按实际上游量化结果重新定标；单项最优不等于联合最优。

## 6. 允许的结论

- 能报告该代理集上输出误差、尾部与普通对照的变化。
- 不能据此宣布格式普遍更优、整模涨点，或允许在线逐张量oracle搜索。
- 进整模前仍需真实权重、可部署在线规则、真实后端；复用已有同范围证据，不机械追加全部阶段。
