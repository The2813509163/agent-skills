# Kernel 子任务：启动指令与交付

由主会话填写；替换尖括号占位符。已有任务卡或文件能说明的内容直接给绝对路径与相关入口，不要求复制全文或另建计划文档。

## 启动 prompt

```text
你是本次 kernel worker。先读取 <kernel-worker/SKILL.md绝对路径>，按下述任务独立执行。
可按需读取 <pytorch-perf-tuning目录绝对路径> 的参考；不要假设能看到主会话历史。

目标与范围
- 主线任务：<这段加速服务的研究／评测>
- 热点：<模块/函数/连续操作；现有耗时与调用频次证据路径>
- 本次产物：<一个语义连贯片段或紧密相关的一组分型核>
- 接口：<函数签名、输出shape/dtype、是否原地修改、状态读写；接回位置>

可信参考与工作负载
- 源码基准：<仓库、commit/摘要；未提交改动的明确只读快照>
- 参考实现：<文件与入口>；回放：<输入/配对权重/mask/分组等路径与执行命令>
- 支持范围：<真实shape族、dtype、stride、归约轴、prefill/decode等阶段>
- 不变量：<算法定义、统计组、舍入/cast顺序、padding/样本独立性及数值域>
- 正确性：<逐值或事先约定容差；真实输入与边界；必要状态/backward检查>

执行与权限
- 工作区：<独立绝对路径>；可改：<候选文件范围>；输出：<工件目录>
- 环境：<解释器/激活命令、依赖复用方式、导入路径>；设备：<分配与可见设备映射>
- Atrex：<仓库绝对路径、已核对revision；知识模式/完整引擎就绪情况与evaluator入口>
- 预算：<本任务总时限/资源上限、必要迭代或停滞限制；包含编译和验收>
- 自主范围：预算内实现、修复和调优。语义缺失、新平台适配、资源不可用或增预算返回主会话。
- 资源与文件只有一个写入者；完整Atrex内部Agent开发时，外层worker不竞争编辑候选。

测量与收口
- 局部：预热后首尾一对设备Event包住100次调用，循环内无Event/同步/取值；逐轮数据落盘。
- 同输入同环境交错对照；图重放单列，编译和准备成本单列，不修改参考/输入/计时契约。
- 正确且可靠获益，或预算用完/方向停滞即返回最佳已验版本；不自动扩展到其他热点。
- 本任务承担<局部/指定调用链>验收；主会话负责接入与必要的整模host验收。
```

- 若环境尚未核对，写明未知；不把“机器上有 Atrex”写成“完整引擎可运行”。
- 恢复时继续给同一工作区、任务标识与最新合格候选；核对进程后再启动，避免重复占卡。
- 同一语义片段的关联形态可合成一个有界任务；无依赖的多个热点另评估资源与预算，不默认一核一个 Agent 或并行全开。

## 返回主会话

```text
结果：可接入 / 保留参考 / 阻塞（原因）
候选：工作区、commit或源码摘要、文件与入口
正确性：通过范围、误差、未验证范围；证据路径
性能：参考→候选；Event100 eager/graph分别标注；逐轮数据路径
接入：调用方式、支持边界及参考回退；整模验收是否尚待主会话完成
成本与收口：实际投入、停止原因、剩余任务进程状态；日志路径
```

不返回整段调试转录；编译成功或一次最快值不等于通过。需要主会话决策时只附阻塞证据、具体选择与推荐。
