# 材质与光：分层，不是给每块加阴影

2026-10-26 建立（v4.0）。实测口径：Supermimic、Fireworks、Firecrawl docs 的计算样式，以及本机 `assets/ui-lab/themes/cupertino.css` 的可运行实现。**这份文件回答"表面为什么看起来有厚度"**，动效归 [motion.md](motion.md)，构图归 [style-menu.md](style-menu.md)。

一句话：**平面的边界靠环，厚度靠高光和落影，锃亮只给主操作。**

## 一、先判层级职责

每个表面只承担一种职责，混在一起就是"塑料拼盘"：

| 职责 | 视觉手段 | 不该有的 |
| --- | --- | --- |
| 贴地：卡片、KPI、行容器 | 半像素环 + 极小落影 | 顶缘高光、渐变填充 |
| 内嵌：输入框、分段轨道、进度槽 | inset 影 + 比画布略深的填充 | 落影（一有影就浮起来了） |
| 浮起：菜单、popover、tooltip、toast | 环 + 中距离落影（可叠磨砂） | 大面积渐变、彩色辉光 |
| 动作：主按钮、关键开关 | 渐变填充 + 顶缘高光 + 双层落影 | 大圆角胶囊化一切 |

判据：把这块的阴影删掉，它还读得出是同一层吗？读不出，说明层级本来就该靠色阶/间距，不靠影。

## 二、四层配方

单层 `box-shadow` 出来的是"贴纸"，四层才像有厚度的物体。四层各管一件事，缺一层就塌。

```css
--elev-2:
  0 0 0 .5px rgba(0, 0, 0, .10),          /* ① 环：给边缘一条可读的界线 */
  0 1px 2px rgba(0, 0, 0, .05),           /* ② 接触影：贴地，短而硬 */
  0 4px 12px -4px rgba(0, 0, 0, .07),     /* ③ 落影：说明离地高度 */
  0 14px 34px -12px rgba(0, 0, 0, .12);   /* ④ 环境影：可省，大容器才加 */
```

| 层 | 作用 | 常见错法 |
| --- | --- | --- |
| 环（0 0 0 .5px） | 在浅色画布上把边界说清楚，比 1px 描边更细、更"玻璃" | 直接省掉，只留影 → 边缘糊 |
| 接触影（y≈1px，模糊≤2px） | 让物体真的落在面上 | 模糊给到 8px → 悬空、发灰 |
| 落影（负 spread，模糊 12–34px） | 表达能力/层级，不表达大小 | 透明度 > .18 → 脏 |
| 环境影 | 大面板、模态 | 每个卡片都加 → 全页发灰 |

**环与描边二选一。** 同时给 `border: 1px` 和环，边缘会重影；`border` 还占布局、改状态时跳动。要 1px 实边就把它写进环：`0 0 0 1px`。

## 三、海拔阶梯

只允许五级，跨级要有理由（弹层比触发它的控件高一级，不跳两级）：

| 级 | 场景 | light | dark |
| --- | --- | --- | --- |
| 0 | 页面分区、表格 | 无影 | 无影 |
| 1 | 内嵌：输入、轨道、选中槽 | `inset 0 1px 2px rgba(0,0,0,.06)` | `inset 0 1px 2px rgba(0,0,0,.45)` |
| 2 | 贴地容器：卡片、KPI | 上面的 `--elev-2` | 抬亮表面 + `0 0 0 .5px rgba(255,255,255,.08)` |
| 3 | 浮起：菜单、popover、toast | `0 0 0 .5px rgba(0,0,0,.08), 0 2px 6px rgba(0,0,0,.06), 0 24px 48px -16px rgba(0,0,0,.24)` | 抬亮 + `0 0 0 .5px rgba(255,255,255,.10), 0 24px 48px -16px rgba(0,0,0,.6)` |
| 4 | 模态、命令面板 | 3 级 + 全屏 `rgba(0,0,0,.28)` 遮罩 | 遮罩 `rgba(0,0,0,.55)` |

深色下投影几乎不可见，厚度靠**表面明度差**（每级 +3–5% L）与 1px 亮环，不靠更大的黑影。

## 四、锃亮按钮

"锃亮"不是 `filter: brightness(1.2)`，是**光在三层上的分布**：上缘一条高光、中间一段上浅下深的填充、下缘一条内影。三者同时存在才有金属/玻璃感。

### 几何

| 尺寸档 | 高 | 横向 padding | 圆角 | 字号 |
| --- | --- | --- | --- | --- |
| 紧凑（表格行内） | 28–32px | 10–12px | 8–10px | 12–13px |
| 默认（表单、工具栏） | 34–40px | 14–16px | 10px | 13–14px |
| 主操作（页头、空态） | 44–52px | 20–24px | 10px 或 980px 胶囊 | 15–17px |

胶囊只给"一次性的强动作"（订阅、开始、继续）。工具栏里一排胶囊会把操作距离和层级一起废掉。

### 状态矩阵

```css
/* 填充：三段渐变，中段最亮，末段压深 —— 模拟弧面受光。
   最亮端已到 #0071e3（白字 4.70:1），再亮就跌破 4.5。 */
--gloss-fill: linear-gradient(180deg, #0071e3 0%, #0068d8 55%, #0059bd 100%);
--gloss-shadow:
  inset 0 1px 0 rgba(255, 255, 255, .48),   /* 顶缘高光 */
  inset 0 -1px 0 rgba(0, 0, 0, .14),        /* 底缘内影 */
  0 0 0 .5px rgba(0, 64, 133, .55),         /* 彩色环：跟填充同色相、更深 */
  0 1px 2px rgba(0, 58, 120, .30),          /* 接触影 */
  0 6px 16px -4px rgba(0, 80, 170, .42);    /* 落影，带填充的色相 */
```

| 状态 | 填充 | 影 | 位移 |
| --- | --- | --- | --- |
| rest | 三段渐变 | 5 层（上表） | 无 |
| hover | 同渐变（**不加亮**） | 顶缘高光提到 .62，落影放大一档 | `-0.5px` |
| active | 整段压深（`#0068d8 → #0050ad`），顶部高光换成 `inset 0 2px 6px rgba(0,40,92,.38)` | 去掉落影，只留内影 | `+0.5px` 并 `scale(.99)` |
| focus-visible | 不变 | 追加 `0 0 0 4px rgba(0,113,227,.26)` | 无 |
| disabled | 灰填充，去高光 | 只剩环 | 无，`cursor: not-allowed` |
| loading | 不变，文字换 spinner | 不变 | 不改变宽度 |

**对比度红线**：白字压在填充上需 ≥4.5:1。苹果蓝 `#0071e3` 是 4.70，已接近上限，所以 hover **不提亮填充**——提亮到 `#0077ed` 就掉到 4.32。想要 hover “变亮”的观感，靠提高顶缘高光与落影，不靠改填充。若品牌色更浅（如天蓝、青色），改用深色字而非白字。

**按下必须换材质，不能只缩放。** 只 `scale(.96)` 是果冻；把高光换成内影，按钮才像真的被压进表面。

### 剂量

| 位置 | 锃亮？ |
| --- | --- |
| 页面主操作（一个） | 是 |
| 关键 toggle / 开关的开启态 | 可以，弱一档（高光 .30） |
| 次要按钮、工具按钮 | 否 → 控件填充 + 内嵌高光 `.5px` |
| 表格行内按钮 | 否 |
| 导航项 | 否 → 选中给一级表面 |
| 大面积面板、Hero 背景 | 否 → 渐变只在按钮/开关这种小面积上 |

一屏出现两个以上锃亮按钮，就等于没有主操作。

## 五、磨砂（translucency）

磨砂是"浮起层的证据"，不是背景装饰。

```css
.popover {
  background: rgba(255, 255, 255, .72);
  backdrop-filter: saturate(180%) blur(20px);
  box-shadow: 0 0 0 .5px rgba(0, 0, 0, .08), 0 24px 48px -16px rgba(0, 0, 0, .24);
}
@supports not (backdrop-filter: blur(1px)) {
  .popover { background: #fff; }
}
```

| 规则 | 理由 |
| --- | --- |
| 只给顶栏、侧栏、popover、tooltip、toast | 正文与表格透出底图会毁掉对比度 |
| 一屏 ≤2 个 backdrop-filter 层 | 每层都是实时合成；滚动容器里尤其贵 |
| 不叠玻璃 | 玻璃叠玻璃后文字对比度不可预测 |
| 必须有不透明兜底 | Firefox 旧版、低端设备、打印 |
| 模糊 16–24px、saturate 1.6–1.8 | 更小像脏，更大像白内障 |

## 六、颜色与光

- **影要带色，不要纯黑。** 中性底用 `rgba(0,0,0,.x)` 即可；带主色的物体用同色相暗值（蓝按钮配 `rgba(0,80,170,.4)`），否则影会发灰。
- **光温跟画布走。** 冷白画布配纯白高光；暖白/米色画布把高光降到 `rgba(255,252,246,.6)`，否则上缘会偏青。
- **深色不叠黑影。** 用 `rgba(0,0,0,.6)` 只在模态遮罩；容器用亮环 + 抬亮表面。
- **一个强调色。** 强调色出现在主操作、选中态、一条数据系列；出现在五个地方就不再表示"这里"。

## 七、塑料感诊断

| 症状 | 成因 | 修法 |
| --- | --- | --- |
| 像贴纸 | 只有一层影 | 补环 + 接触影 |
| 发灰发脏 | 落影透明度过高、模糊过大 | 落影 α ≤ .12，负 spread |
| 塑料玩具 | 渐变跨度过大 + 上下都有高光 | 渐变只走上浅下深；高光只在上缘 |
| 果冻 | 圆角 > 高度的 1/2 且到处用 | 圆角按尺寸档，胶囊只给一次性动作 |
| 白字看不清 | 填充过亮，白字对比度 < 4.5:1 | 压深填充，或改用深色字（见对比度红线） |
| 霓虹 | 彩色 glow（`0 0 40px accent`） | 删掉，改同色相低透明落影 |
| 玻璃墙 | 3 层以上 backdrop-filter | 只留最上面一层 |
| 浮雕 | 顶部和内嵌同时亮 | 内嵌层不给顶缘高光 |

## 八、验收（可测，不靠眼）

在真实页面上取计算样式，逐条对：

```js
const cs = el => getComputedStyle(el);
const layers = s => s === "none" ? 0 : s.split(/,(?![^(]*\))/).length;
layers(cs(document.querySelector(".btn.primary")).boxShadow);        // ≥ 4
cs(document.querySelector(".card")).boxShadow.includes("0.5px");      // 环存在
cs(document.querySelector(".card")).borderTopWidth;                  // "0px"（环代替描边）
cs(document.querySelector(".top")).backdropFilter;                   // 有值则有兜底
document.querySelectorAll(".btn.primary").length;                    // 一屏 ≤ 1
```

再加三条肉眼项：

1. 阴影删掉后，层级是否仍可读（说明结构本来就对）。
2. 125% 缩放与深色下，环是否仍看得见。
3. `prefers-reduced-motion` 下，按下位移消失但**材质变化仍在**。

### 本机实测（cupertino，2026-10-26）

把按钮单独截图像素化（Gamma 编码亮度），按行均值：

| 行 | 亮度 | 对应 |
| --- | --- | --- |
| 0 | 77.6 | 外环（比填充暗） |
| 1 | 172.4 | 顶缘 1px 白高光（比填充亮 +76.8） |
| 2–4 | 96.5 / 96.0 / 95.6 | 填充顶端 `#0071e3`（理论 97.2） |
| 中段 | 90.6 | `#0068d8`（理论 90.2） |
| 底段 | 80.3 → 78.6 | 接近 `#0059bd`（理论 77.2） |
| 倒数第二行 | 66.4 | 底缘内影 |

也就是说：高光、渐变、内影三者都在，且方向正确（上亮下暗）。同时对每个渐变 stop 算了白字对比度：`#0071e3` 4.70、`#0068d8` 5.29、`#0059bd` 6.64；按下态 5.29–7.63。按下过渡实测 110ms。

材质对了不等于审美通过；这两件事分开报。
