# 已确认偏好与操作索引：按范围使用

这份表保存真实反馈，不是页面模板。T15（2026-10-08）要求 Agent 主动引导设计；T16–T18（2026-10-26）把审美基线拉到「现代、有交互、有材质」，同时点名一批已经过时的方向。T01–T14 的认可与拒绝仍在各自范围内有效，但冲突时以 T16–T18 为准。

## 先辨认记录的性质

- **适用的偏好**：控件易用、图表焦点联动、透明等宽导航等；在对应任务继承
- **局部选择**：科研折线、某主题的灯带辉光、右侧图例等；不推导为所有页面只能如此
- **实现参考**：42px、某个 hex、四种演示骨架；可因设备、内容与品牌调整，不是已确认的全局验收阈值
- **历史事件**：旧样板的黑底、药丸宽度与塑料感；原因/证据见 evolution，不把拒绝一个实现扩大为禁用整个设计方法

同一风格可有不同构图、字号和密度。工作控件使用无衬线，不阻止叙事标题采用衬线；工作台不做干扰操作的长动画，不阻止产品介绍用滚动章节。新形式无需先得到一个历史 T/S 编号才能尝试。

## 当前确认的偏好

| --- | --- | --- | --- |

| T03 | 表单、筛选、按钮 | 柔和灰底、细微边界、适度圆角、轻阴影、清楚的 hover/focus/选中态 | 每个元素都像独立代码框；高对比粗描边、厚重阴影 |
| T04 | 整体一致性 | 导航、概览、列表、详情、设置和统计共享视觉语言 | 只美化一页，其他页面保留旧代码框风格 |

| T10 | 每日时间点选择 | 明确的 24 小时制 `00–23`；新增时间分钟默认 `00`，允许主动选其他分钟 | AM/PM 切换；空值弹出后分钟跟随当前时间；默认值在保存时被误添为时间点 |

| T14 | 现代工作界面的导航与搜索 | 同组导航等宽、整行可点击；常态透明不显按钮框，hover 轻反馈、选中才常驻圆润浅底；胶囊搜索框、易命中的字号/高度、按下微压、键盘焦点清楚 | 导航每项常态白底描边；为照搬参考把按钮缩成小文字药丸；只有文字附近可点；焦点把圆角改方；不推广为大面板必须胶囊 |
| T15 | 全部 UI 设计合作 | Agent 从内容主动建议更直观、更好看的结构、叙事与交互，展示可逆候选并引导比较；个人偏好按范围校准 | 只照旧样板换皮；把用户审美经验当能力上限；只列禁令、不提供正向设计；为了惊艳擅改局部任务或业务功能 |
| T16 | 材质与按钮（全部产品界面） | 主操作有真实的材质：上浅下深的填充、上缘一条高光、下缘内影、半像素环、带色相的落影；按下时材质真的变化（110ms 内压进去）；浮层用磨砂 + 环；一屏只留一个锃亮主操作 | 纯色扁平主按钮（看着像没做完）；只有落影、没有环和高光的“塑料块”；霓虹式彩色辉光；一屏多个抢眼主按钮 |
| T17 | 现代感与交互密度 | 每个状态都有答复：hover、press、focus-visible、selected、disabled、loading、empty、error；内容切换有 180–240ms 短转场；共享元素/浮层从触发处出现；弹簧只用于手势驱动的运动 | 只有 hover 没有按下；满页 fade-and-rise；`scale(.9)` 当按压；滚动劫持；无限循环装饰；`outline:none` 后无替代 |
| T18 | 苹果式排版与密度 | 系统字体栈优先（`-apple-system`/SF/PingFang）；大字号配负字距、600 而非 800；行高紧凑；留白靠间距而不是靠卡片；胶囊只给一次性强动作 | 把每段都放大当“高级”；所有按钮都做成胶囊；用圆角大小冒充苹果感；像素级模仿 macOS 组件 |

## 已陈旧：保留范围，不再作为默认

判断依据是外部审美已整体换代，不是用户改口。这些方向仍可用，但**不能作为“好看/高级”的默认答案**；用了要说明为什么是它，而不是随手拿了旧样板。

| 方向 | 现状 | 还能用在哪 |
| --- | --- | --- |
| 奶油米色 + 陶土橙（paper-cream） | 2025–2026 最可辨认的 AI 生成外观；单独用陶土橙已是信号 | `paper-cream` 仅限“文档/阅读/纸面”场景，且不再是高级感代名词 |
| Bento 大圆角白块 = 苹果风 | 圆角不是材质；bento 只是布局手法 | 内容以预览/图片为主时的布局选择，不承担“苹果感” |
| 磨砂玻璃作为通用表面 | 玻璃叠玻璃、满页 blur 已成 slop | 只用于顶栏/侧栏/popover/toast 等浮起层 |
| 紫色/靛蓝渐变、渐变文字、霓虹 glow | 第一代 AI 页面的识别符 | 品牌本身拥有该色时按品牌走 |
| “只靠阴影、无边界”的按钮 | 仍然否决——但否决的是**缺环、缺高光、只堆落影**，不是锃亮本身（见 T16） | 不再有任何场景需要这种做法 |
| 静态“完成度”当交付 | 没有 hover/press/loading 的界面视为未完成 | 不再作为可接受的交付 |

## 旧问题快速索引

用户报告问题时，先按症状直达对应模式，复现其实际数据密度，再选择最小修复。不要求事先预测所有问题，也不将每次局部解决办法强制应用于所有页面。

| 用户描述的症状 | 直接查阅 |
| --- | --- |
| 图例按钮点亮/点灭与曲线可见性对不上，有的灰了还可见 | patterns.md §1：图例开关按名称选择、系列重名导致脱钧 |
| 基线/起点被画成孤零零的点，不参与曲线 | [S03 §2](../scenarios/research-charts.md)：标量固定值画水位参考线；先判互斥性再选分页或叠加 |
| 柱状图看不出东西/想撤掉；想看折线 | [S03 §1.6 / §3](../scenarios/research-charts.md)：折线是主视图，指标选择器放折线图头部 |
| 数据集/方法被做成只能选一个；想同时看但可隐藏 | [S03 §1.3 / §2](../scenarios/research-charts.md)：每数据集一幅图 + 可见性开关；只有实验批次互斥 |
| 曲线高亮了，但信息框没有突出对应条目；其他条目没变淡 | patterns.md §1：统一焦点与真实命中验收 |
| 提示框挡住折线、点不到其他线；信息太多看不全、不能滚动；两图并排画布太小 | [patterns.md §2.1：密集图表详情遮挡](../patterns.md#dense-chart-details) |
| 信息被移到图下，要低头找，失去悬浮查看的直觉 | patterns.md §2.1：恢复目标附近浮层，优先扩大画布、自动避让和限高滚动 |
| 最右侧信息框被挤窄、名称折行、超出边界 | patterns.md §2：自然宽度与定位翻转 |
| 筛选要反复滚到页面顶部 | patterns.md §3：筛选就近 |
| 分别有对象/资源/服务排行，仍找不到谁通过什么做了什么 | S04 §1–§2：由关系问题推导联合排行与组合明细 |
| 想合并某个区别，又想逐层展开找原因 | S04 §3：维度汇总与折叠下钻的不同语义 |
| 状态/动作又出现在资源列表，筛选互相矛盾 | S04 §4：语义去重与依赖筛选 |
| 展开或翻页后小计对不上，返回后条件丢失 | S04 §5–§6：完整小计、状态连续性与排查路径验收 |
| 汇总比例、峰值、去重数或直接相加后对不上 | [数据与运行约定](data-and-runtime.md) §1：指标合并条件 |
| 快照轮询、缺测、滚动窗口、重启后的历史数字不可信 | 数据与运行约定 §2–§3：采集差分、时间边界与质量状态 |
| 页面已好，但历史留存、进程重启或升级恢复没验证 | 数据与运行约定 §4–§5：持久化和运行方式 |

## 工作型界面的控件起点

下面是**未选主题时的兜底起始值**，已有项目优先沿用其体系。主题数值见 [themes/](../themes/README.md)；旧基线“灰蒙蒙”的问题是层次与字体控制不足，不是否决中性灰设计。

| 项目 | 起点 | 调整原则 |
| --- | --- | --- |
| 字体 | 产品界面优先系统字体栈 `-apple-system, BlinkMacSystemFont, "SF Pro Text", Inter, "PingFang SC", "Noto Sans SC"`；数字 tabular-nums | Inter 不覆盖中文；需要一致渲染时才自托管，字体交付与字重按 visual-craft.md |
| 标题字距 | ≥20px 的标题与指标数字用 `-0.02em` 至 `-0.032em`，字重 600 | 小字号不加负字距；不用 800 冒充高级 |
| 表面 | canvas `#f7f8fa`；panel `#fff`；control `#f3f4f6` | 层次来自轻微灰阶差别，不给每格套框 |
| 文本 | primary `#252b35`；secondary `#626c7b` | 辅助文字仍需可读；不要用低对比制造"高级感" |
| 边界/强调 | 使用所选主题的边界、主操作、hover、选中与焦点 tokens | 中性主题可用深灰主操作；亮蓝按主题采用，状态色只承载状态 |
| 圆角 | 控件 8–10px，面板 10–16px；胶囊（980px）只给一次性强动作 | 不要把所有大容器和按钮都做药丸 |
| 密度 | 紧凑表单字约 12–14px、控件高约 32–36px，正文按场景放大 | 小屏/触摸目标增大命中区；不是把字做小就叫紧凑 |
| 海拔 | 贴地容器：半像素环 + 接触影 + 落影；浮层再抬一级并加磨砂 | 每级职责见 [material.md](material.md)；不给静态卡片补顶缘高光 |
| 主操作材质 | 三段渐变 + 顶缘高光 + 内影 + 彩色环；一屏一个 | 次要操作只用控件填充，不抢主操作 |
| 动效 | 颜色/hover 140–180ms；按下 90–120ms；浮层 160–200ms（关闭更快）；内容切换 180–240ms；页面级 300–450ms | 曲线与弹簧规则见 [motion.md](motion.md)；不为时长加动画 |
| 数字 | UI 字体 + `font-variant-numeric: tabular-nums` | 数字对齐不需要整页等宽 |

### 具体控件

- **导航/搜索**：按 T14，同组导航整行等宽、常驻导航高约 42px；搜索采用圆润边界。分组和层级保留，不以缩小命中区换取“精致”。
- **输入/选择器**：柔和灰底、细或透明边框、非等宽字；focus 可变白底配清楚焦点环。选择器有自然的小箭头。
- **分段选择**：灰色轨道 + 浅色/白色活动项、轻阴影；选中靠底色/字色，不靠厚边框。
- **多选菜单**：轻浮层、圆角搜索框、整行 hover、清楚的复选选中态和已选数量；原生语义优先。
- **表格**：浅表头、细行分隔、轻微行 hover；属性名称直接显示，无需代码字体/代码背景。
- **状态灯带**：细矩形红黄绿长历史（T08），状态清楚、悬浮可查；modern-saas 可用鲜艳色与辉光，克制主题用实色及轻微反馈。
- **有序列表**：紧凑行、序号、主名称 + 次级信息、可发现的拖拽柄；同时有键盘排序或按钮替代。
- **状态标签**：柔和彩色底 + 可读文字，配点或图标；不要让颜色成为唯一信息来源。
- **每日时间点**：采用 T10；优先复用现有控件，原生 time 无法稳定显示 24 小时制时，可用原生小时/分钟 select。默认分钟不代表用户已选小时，具体行为见 [patterns.md](../patterns.md#7-每日时间点24-小时制与整点默认)。
- **跨页**：在共享 tokens/组件/样式层修改，再处理专用覆盖；别堆一份全局 `!important` 覆盖来掩盖冲突。
- 真正代码编辑器、日志原文等仍可用等宽；“不喜欢代码块感”不等于篡改真实代码的呈现需求。
