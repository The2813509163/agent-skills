# Soft UI Evolution · 柔和亲和主题（降亮版）

> **v4 材质校准（2026-10-26）**：内阴影凹入 + 外阴影浮起是**新拟态**的判据，与 material.md 的“浮雕”诊断方向相同。本主题保留柔和色彩与圆润字形，但材质限制为：**只有输入框/分段轨道用内阴影**；按钮与选中项改控件填充 + 环 + 短接触影，不再“双影夹击”。按下要有材质变化（内影），不能只下沉 1px。

- 来源：UI/UX Pro Max #19；初版整体太亮刺眼被用户指出，2026-10-04 降亮后 Confirmed，复验待定。
- 气质：柔和色彩、圆润字形、轻层级；4.5:1 对比优先，不做新拟态糊。
- 默认适用：轻量/亲和向工具、表单为主的设置页。

## 组件处理要点

- **输入框/分段轨道**：内阴影凹入（本主题唯一的“凹”）；其它表面不再凹。
- **按钮**：控件填充 + 环 + 短接触影；按下换内影 + `scale(.99)`，不只下沉 1px。主操作可用轻渐变 + 顶缘高光（见 material.md），但本主题不做大幅 glossy。
- **导航活跃项**：白底 + 环；不用“外阴影浮起”的双影写法。
- **焦点**：`:focus-visible` 用 3px `rgba(91,141,239,.55)` 粗环（柔和主题下细环看不见）。
- **标签**：字重 700。
- 警惕亮度回弹：canvas 不得亮于 `#eef2f9`（初版刺眼教训）。
