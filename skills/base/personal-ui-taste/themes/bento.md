# Bento Box · 预览/画廊主题

> **v4 材质校准（2026-10-26）**：本主题的定位是**布局手法**（大圆角、预览主导、卡片分区），不是材质主张。原文「无边界、层级全靠阴影」以及“面板/按钮无边框只给阴影”已被 [material.md](../references/material.md) 取代——那正是被判为“塑料块”的写法。现用：环 `.5px` + 接触影 + 落影；只靠阴影、不给环的做法不要再从本文件抄。卡片 hover 仍可上浮，但不能只靠影。

- 来源：UI/UX Pro Max #39（Apple 气质）；2026-10-04 用户对比验收 Confirmed。
- 气质：大圆角白块浮在浅灰画布上；层级靠灰阶 **加环与轻影**，不靠无边界堆阴影。
- 默认适用：S02 预览型工作台、卡片画廊、内容以图片/预览为主的页面。

## 组件处理要点

- **面板/KPI**：环 + 轻影；边框宽度归零（环画在边框盒外，留 1px 会出缝）。
- **卡片**：hover `translateY(-3px)` + 阴影升一档（画廊的核心反馈）；戒指环仍在，不做“无边界浮块”。
- **侧栏**：融入画布；活跃项白底 + 环浮起。
- **顶栏**：半透白 + `blur(12px)`；必须有不透明兜底。
- **按钮**：默认控件填充 + 半像素内高光 + 环；主按钮可用一层轻渐变 + 顶缘高光（完整状态矩阵见 material.md），但**不要只给阴影**。
- **表格**：行分隔 `#f0f0f2`，表头 `#f5f5f7`。
- 注意：信息密集表格场景慎用本主题（大圆角与低边界会降低扫描线感），它服务预览而非排查。
