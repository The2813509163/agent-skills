# Cupertino · 分层的光

- 来源：2026-10-26 实测 Supermimic、Fireworks、Firecrawl docs 的计算样式，加 Apple 系统色口径；本机实现见 [ui-lab/themes/cupertino.css](../assets/ui-lab/themes/cupertino.css)。
- 气质：浅灰画布上浮着白面板，边界是半像素环而不是描边；主操作有真实的材质（上浅下深的填充、顶缘高光、底缘内影、带色相的落影）；浮层磨砂。
- 默认适用：产品界面、设置、工作台、营销页的交互区。**不是"苹果模仿秀"**——不复制 macOS 窗口控件，只借它的光与排版纪律。

## 实测依据

| 站点 | 可借的 | 不借的 |
| --- | --- | --- |
| Supermimic | `#f5f5f7` 画布 / `#1d1d1f` 正文 / `#6e6e73` 次级 / `#e8e8ed` 控件填充；环 `0 0 0 1px rgba(0,0,0,.06)` + `0 6px 24px rgba(0,0,0,.04)`；`saturate(1.8) blur(20px)`；80px 标题配 `-1.2px` 字距、字重 600；缓动 `cubic-bezier(.28,.11,.32,1)` | 全站 0.9s 入场（工作界面太慢） |
| Fireworks | 暖白 `#f9f7f5` 配深酒红 `#280016` 墨色；96px 胶囊按钮、52px 高、16px 字号；衬线标题 `-0.03em` 字距 | 边缘彩色光晕（品牌专属，通用界面会变霓虹） |
| Firecrawl docs | 12/16px 圆角层级、`#ff4d00` 单强调、150ms 微交互、按钮下缘 `inset 0 2px 0` 彩色高光 | 文档站的密集表格节奏 |

共同点只有三条：**中性色阶拉开层次、一个强调色、微交互快（150–300ms）**。所谓"苹果感"来自这三条加材质，不来自圆角大小。

## 组件处理要点

- **主操作**：三段渐变（`#4da3ff → #0a78e8 → #0062c9`）+ 顶缘 `inset 0 1px 0 rgba(255,255,255,.48)` + 底缘内影 + 彩色环 + 双层落影。hover 提亮并升 -0.5px；按下换成内影、`scale(.99)`、下移 0.5px。一屏只留一个。
- **次要按钮**：`#e8e8ed` 填充 + 半像素白色内高光 + 环；hover 提亮一档；按下变深并加内影。**不要给次要按钮也上渐变**——主次就没了。
- **导航**：常态透明、整行命中；hover 只换底色；选中才拿白底 + 一级海拔。不做每项白底描边。
- **分段选择**：灰轨道（内嵌），白色 thumb 靠环 + 短影离开轨道；不开渐变。
- **顶栏 / 浮层**：`rgba(255,255,255,.72)` + `saturate(180%) blur(20px)` + 环；必须有不透明兜底。
- **面板**：分区用发丝线或留白，不做卡片墙；真正的容器（KPI、摘要、卡片）才给环和影。
- **表格**：发丝行线 `.5px`，表头透明 + 下缘线；不给表头铺底色块。
- **危险操作**：浅红底 + 深红字 + 极淡红环；不用锃亮材质，避免"闪亮的删除键"。

## 与其他主题的边界

- 和 **bento** 的区别：bento 是"大圆角白块 + 无边界"的**布局手法**，常被叫作苹果风但并不是苹果材质；cupertino 的识别点是环、高光与排版，圆角只是结果。
- 和 **shadcn-neutral** 的区别：shadcn 用中性深灰主操作、1px 边界、零高光，更"工具"；cupertino 用蓝色强调、环、材质，更"产品"。
- 和 **paper-cream** 的区别：那个是纸面阅读向，暖调；cupertino 是冷灰中性 + 光。
