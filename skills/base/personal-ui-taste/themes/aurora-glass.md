# Aurora Glass · 玻璃质感主题（限浮层）

> **v4 材质校准（2026-10-26）**：玻璃降为**只在浮起层**（顶栏、popover、toast），一屏 ≤2 层；面板与卡片改不透明表面 + 环。原文中“面板/卡片/图例统一 blur(16px)”、“主按钮蓝紫渐变”、“焦点与灯带辉光”三项已停用——分别命中满页玻璃、紫蓝渐变、霓虹辉光三条否决。

- 来源：UI/UX Pro Max #10 + #3；初版多色极光渐变背景被用户否决（“看着别扭”），2026-10-04 去除渐变后 Confirmed。
- 气质：平色浅蓝画布 + 浮起的磨砂层，轻盈通透；玻璃只作**浮层**材质，不做背景特效、不做面板墙。
- 默认适用：需要毛玻璃导航/浮层的场景；作为其他主题的浮层材质也可借用。

## 组件处理要点

- **面板/卡片/表格**：不透明白 + 环；**不给 blur**——面板面积大，一上玻璃就会遮住底图、毁掉正文对比。
- **侧栏/顶栏**：`rgba(255,255,255,.55)` + `blur(18px)`（仅此两处可用常驻玻璃，共 2 层）。
- **主按钮**：实色 `#0073e6` + 顶缘高光 `inset 0 1px 0 rgba(255,255,255,.35)` + 环（不用蓝紫渐变，那个方向已否决）。
- **焦点**：`0 0 0 3px rgba(0,115,230,.28)` 环；**不用 `drop-shadow` 辉光**。
- **灯带**：实色段带 + 环；**不用 `0 0 8px currentColor` 辉光**（暗底上可保留微弱 glow，白底上只会变脏）。
- 必须给 `@supports not (backdrop-filter: blur(1px))` 留不透明兜底。
